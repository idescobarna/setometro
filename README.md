# Setómetro

Aplicación web para estimar dónde es más probable encontrar setas, según la especie, el terreno, la geología, la lluvia, la temperatura y las citas reales.

**Abrir la app:** https://idescobarna.github.io/setometro/

## Qué tiene en cuenta
- Lluvia, temperatura, humedad del suelo, nieve, evaporación y viento (Open-Meteo), con corrección opcional por estaciones de AEMET.
- Altitud, pendiente y orientación de las laderas.
- Vegetación, pistas y espacios protegidos (OpenStreetMap).
- Geología (IGME, mapa GEODE 1:50.000) para estimar si el suelo es ácido o calizo.
- Citas reales de cada especie (GBIF) y fotos (Wikimedia Commons).

18 especies de otoño y primavera. La puntuación es una estimación relativa, no una garantía: nunca consumas una seta sin identificación segura por un experto y respeta la normativa de recolección de cada monte.
